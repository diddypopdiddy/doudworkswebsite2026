# Studio room composition studies

These artifacts are non-production experiments. They do not replace the locked
room shell, registered layers, standalone object masters, website imagery, or
published homepage.

## Primary comparison

- `one-shot-cohesive-render-v1.png` — a single generative cohesion pass using
  the backward-worked composition as its strict reference. It tests what a
  one-shot render gains in common lighting, grounding, and material language,
  and what it loses in exact object identity and shell fidelity.
- `backward-worked-draft-v3.png` — a deterministic Stage B composite built from
  the locked `00-room-shell.png`, current registered placeholders, higher-detail
  standalone candidates, two room-camera candidate rerenders, separate contact
  cues, and a foreground-wall occlusion overlay.
- `one-shot-composition-v1.png` — the initial deterministic drop-in proof that
  exposed camera, lighting, grounding, and fidelity mismatches. It is retained
  as diagnostic evidence, not a recommended result.

## What the one-shot demonstrates

The one-shot is more cohesive as a single rendered image. It also redraws the
locked shell and individual assets, so it cannot be treated as identity-faithful
or as a direct replacement for the deterministic asset library.

## What the backward-worked draft demonstrates

The backward-worked draft preserves the locked shell and more of the strongest
individual object detail. It is not final integration. Remaining work includes
room-camera rerenders for the unreplaced placeholders, physically specific
contact/cast shadows, wall-mount depth, material grading, and an intentional
mobile composition.

## Rebuild

Run from the Website repository root:

```sh
python3 media/home/studio-room-assets/tools/build_composition_studies.py
```

This rebuilds the deterministic diagnostic and backward-worked draft plus
desktop/laptop/mobile crop proofs. The one-shot generative render is preserved
as a selected comparison artifact and is not regenerated by the script.
