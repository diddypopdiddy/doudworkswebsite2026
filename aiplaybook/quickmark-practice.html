Independent looks like

Practice Mode
Defines situation/roles/constraints, attempts first, checks debrief, then uses an identified improvement in a retry where needed.
Prompting
States a useful goal and audience/context; uses allowed relevant input; requests fitting help; tests response fit; deliberately repairs overreach
Data & Privacy
Screens actual input before sharing; explains identifiability/minimality; uses approved substitutes; stops/asks/notifies appropriately when required
Ethics
Checks permission, honors scope including No AI, describes actual help truthfully, rejects false evidence/unfair assumptions, owns decisions and learning
Verification
Checks important claims against source/test; distinguishes supported, contradicted, and unknown; corrects/withholds responsibly; preserves evidence limits

Write the level N = Not yet · G = With guidance · I = Independent. This sheet names students. Keep it with your class records and out of any AI tool.
