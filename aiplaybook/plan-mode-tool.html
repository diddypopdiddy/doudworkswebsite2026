Tool Mode

Printable lesson plan

Goal Direct a specific operation, then verify and approve the result yourself.

Learning objectives

  1. Students will be able to specify a task, the result they need and what must stay the same.
  2. Students will be able to direct a bounded operation using only approved input.
  3. Students will be able to compare the output with the input and repair material discrepancies.
  4. Students will be able to verify and approve the supported result or withhold unresolved parts.

Key vocabulary

Tool Mode · Operation · Source · The human finish

Materials

Student starter prompt for Tool Mode · Five Mode Studio Student Workbook, Tool section, pp. 38–46 · An approved source and the task criteria

Student starter prompt Turn these notes into [format]. Don't add anything that isn't here. If something is missing, write MISSING instead of guessing.

TimeStepTeacherStudentsSay this
Before class · 5 min in classOpening
Design		Choose a task for this Mode. State what Tool Mode may do, what students must do and which source is approved.Name the task’s limits. Bring: A small approved source you understand and a format or operation you can check.“Today you’ll use Tool Mode. Read the task and point to the thinking that stays with you.”
5 minTeach
Model		Use your saved conversation or the Framework example. Format a short set of notes with one missing entry. Compare every row with the original. Ask for a repair if a value changes and check again.Name one point where the model supported the task and one decision the teacher kept.“Change the format. Keep all the original facts and mark anything the source doesn’t supply.”
2 minTeach
Supply		Hand out the starter prompt, the approved source and the task criteria.Fill in the brackets. Check that the information you share is minimal and approved.“Give it enough context to do the permitted job. What can you leave out?”
20 minPractice
Engage		Circulate. Ask what the learner is keeping, changing or checking. Record the exact wording of a cue that identifies a needed decision.Name what can change and what stays. Run the operation, compare the result with the source, then verify and approve or hold it back.“Point to the part where you directed the help or decided what to do with the response.”
3 minCheck
Share		Use the approved conversation hand-in and confirm the evidence arrives privately.Turn in the task work and the full, dedicated task conversation.“Open what you handed in. Check that the first prompt, every response and your final turn are there.”
5 min · finish reviewing after classCheck
Review		Use the Tool Mode rubric to review the conversation. Mark the finished cycle, record the observed level and give a specific next action.Explain a key decision and point to the turn or class source that supports it.“Show me the evidence of what you checked and what you chose.”
5 minExit
Exit with the human finish		Collect a one-sentence explanation and use it alongside the work and conversation to plan a next attempt.Write a brief answer pointing to your own work.“Which check let you approve the result? What did you do with anything missing?”

Check for understanding Tool Mode rubric, a separate printable. Record the level and the exact cue, if you gave one.

Misconceptions and reteach

  • “The table looks tidy, so it’s ready.” Say: “Check what’s in the table against your original material.” Redo: Trace each row back to the source, including a missing or changed value.
